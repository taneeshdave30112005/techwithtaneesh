**How to publish on GitHub Pages**
1. Create a repository named `techwithtaneesh` (or any name).
2. Upload all files from this ZIP into the repository root.
3. Go to Settings → Pages → Source → Deploy from a branch → `main` → `/ (root)` → Save.
4. Wait 1-2 minutes and open: `https://yourusername.github.io/techwithtaneesh/`

Notes:
- To make contact form work, sign up at https://formspree.io and replace `YOUR_FORM_ID` in contact.html with your Formspree ID.
- Filenames are case-sensitive on GitHub Pages.
